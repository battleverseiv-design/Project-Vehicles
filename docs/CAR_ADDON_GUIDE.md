# 🚗 Полное пособие по созданию транспортных аддонов (CarDecor / Project Vehicles)

> **Назначение пособия:** Исчерпывающее руководство для разработчиков и моддеров по созданию, настройке, экспорту 3D-моделей и балансировке транспортных средств для мода CarDecor (Forge & Fabric 1.20.1).

---

## 1. 📂 Архитектура и структура аддон-пака

Мод поддерживает два формата размещения паков в директории `cardecor_packs/`:
1. **Обычная папка:** `cardecor_packs/<pack_id>/` (идеально для активной разработки и хот-релоада).
2. **ZIP-архив:** `cardecor_packs/<pack_id>.zip` (для готовых релизов и распространения игрокам). Мод автоматически кэширует и распаковывает архив в `.cache/`.

### Дерево файлов аддона
```text
cardecor_packs/<pack_id>/
├── pack.mcmeta                           # Манифест ресурс-пака (автогенерируется, если отсутствует)
├── vehicles/                             # Папка с конфигурациями автомобилей (или cars/)
│   └── <car_id>.json                     # Главный файл параметров транспорта
└── assets/
    └── <namespace>/                      # Рекомендуется использовать <car_id> или общее имя пака
        ├── models/                       # 3D-модели в формате .obj
        │   ├── <car_id>_chassis.obj      # Кузов автомобиля (без колес и руля)
        │   ├── wheel.obj                 # Одно универсальное колесо
        │   ├── steering_wheel.obj        # Рулевое колесо
        │   └── spare_wheel.obj           # (Опционально) Запасное колесо для пикапов/внедорожников
        ├── textures/
        │   └── vehicle/
        │       └── <car_id>.png          # Текстура автомобиля (UV-развертка)
        └── sounds/                       # (Опционально) Кастомные аудиофайлы .ogg
```

> [!NOTE]
> Если в корне пака нет файла `pack.mcmeta`, CarDecor сгенерирует его автоматически (`"pack_format": 15`).

## 2. ⚡ Быстрый старт через команды разработчика

Для создания нового аддона прямо в игре не требуется создавать папки вручную:

1. **Сгенерировать каркас:**
   ```bash
   /car template <id> [category]
   ```
   *Параметры категории:* `sedan`, `pickup`, `sports`, `truck`, `suv`.  
   Команда создаст `cardecor_packs/<id>/`, сгенерирует `pack.mcmeta`, структуру каталогов и полностью заполненный файл `vehicles/<id>.json`.

2. **Проверить ошибки в ресурсах:**
   ```bash
   /car validate [id]
   ```
   Сканирует пак и выводит подробный отчет: проверка наличия `.obj` файлов, текстур, позиций колес, мест и физических лимитов.

3. **Мгновенно применить изменения без перезапуска игры:**
   ```bash
   /car reload
   ```
   Сбрасывает кэш моделей на клиенте и перезагружает параметры автомобилей.

## 3. 📐 Требования к 3D-моделям (.OBJ)

CarDecor использует собственный высокопроизводительный движок загрузки и оптимизации OBJ-моделей. Модели создаются в **Blockbench** или **Blender**.

### Система координат и Origin (Pivot)
* **Масштаб:** `1 единица = 1 метр = 1 блок Minecraft`.
* **Оси:**
  * **+X:** Левая сторона машины (относительно взгляда водителя).
  * **-X:** Правая сторона машины.
  * **+Y:** Вверх (высота).
  * **+Z:** Вперед (нос автомобиля).
  * **-Z:** Назад (багажник).

### Разделение элементов:
1. **Кузов (`chassis`):**
   * Включает кузов, фары, стекла, салон, торпеду, приборную панель, сиденья.
   * **НЕ ДОЛЖЕН** содержать колеса и руль (они анимируются и рендерятся отдельно).
   * Точка Origin `[0, 0, 0]` должна находиться на уровне днища машины строго по центру базы.
2. **Колесо (`wheel`):**
   * Моделируется ровно **одно** колесо.
   * Origin `[0, 0, 0]` должен находиться **строго в центре ступицы/оси вращения колеса**.
   * Колесо устанавливается лицевой стороной (диском) наружу вдоль оси X. Движок автоматически отзеркалит и повернет его для всех 4 позиций.
3. **Руль (`steering_wheel`):**
   * Origin `[0, 0, 0]` должен находиться в центре рулевой колонки (точке вращения).
   * Позиционируется в салоне перед местом водителя. Мод автоматически вращает руль синхронно с передними колесами.
4. **Запасное колесо (`spare_wheel`):**
   * Экспортируется как отдельный меш или привязывается через параметр `spare_wheel_pos`.

## 5. ⚙️ Детальное описание разделов параметров

### 5.1. Физика (`physics`)
* `mass` (кг): Масса машины. Влияет на инерцию, таран препятствий, сцепление с грунтом и тормозной путь. Легковушки: 1100–1400 кг, Пикапы/Внедорожники: 1700–2200 кг, Грузовики: 3500+ кг.
* `top_speed` (км/ч): Максимальная расчетная скорость.
* `horsepower` (л.с.): Мощность двигателя. Определяет динамику разгона на разных передачах.
* `drivetrain`: Тип привода.
  * `"RWD"` — задний привод (склонен к заносу и power oversteer при газе).
  * `"FWD"` — передний привод (стабилен, безопасен, недостаточная поворачиваемость).
  * `"AWD"` / `"4WD"` — полный привод (максимальная проходимость на снегу, грязи и бездорожье).
* `wheelbase` (м): Колесная база (расстояние между передней и задней осью).
* `turning_radius` (м): Радиус разворота (меньше — острее разворот).
* `suspension_stiffness` (Н/м): Жесткость пружин. 14–18 (мягкая внедорожная), 22–26 (городская), 30+ (спортивная жесткая).
* `suspension_damping`: Коэффициент демпфирования амортизаторов (гашение раскачки). Норма: 1.0–1.4.
* `max_suspension_travel` (м): Максимальный ход подвески при проезде кочек и приземлениях.
* `offroad_capability`: Множитель сцепления вне асфальта. 0.6–0.8 (спорткары), 1.0 (обычные авто), 1.5–2.0 (внедорожники).

### 5.2. Колеса (`wheels`)
* `radius` (м): Радиус колеса (половина диаметра). Критически важный параметр для точного контакта с грунтом и работы рэйкастов подвески.
* `front_left`, `front_right`, `rear_left`, `rear_right`: Координаты центров колес относительно центра машины `[X, Y, Z]`.
* `spare_wheel_pos`: `[X, Y, Z]` координаты запасного колеса. Если задано, запаску можно снимать/устанавливать гаечным ключом!

### 5.3. Места и двери (`seats`)
* **Индекс 0** — всегда водительское место.
* `door_name`: Название двери, отображаемое в контекстном HUD при наведении игрока.
* `is_cargo_bed: true`:
  * Объявляет место как **грузовую платформу/кузов пикапа**.
  * Игрок в кузове сидит на открытом воздухе, может вращаться на 360°, свободно стрелять из оружия TACZ.
  * В кузов можно сгружать крупногабаритный инвентарь багажника.
  * На сиденье кузова действует погода (дождь/мороз), в отличие от защищенного салона.

### 5.4. Звуки двигателя (`sounds.engine_type`)
Доступные встроенные типы двигателей:
* `"i6"` — рядная «шестерка» (плавный, породистый звук).
* `"v8"` — американский V8 (басовитый, рычащий звук).
* `"v6"` — современный V6.
* `"i4"` — рядная 4-ка (классический звук малолитражки/седана).
* `"diesel"` — дизельный двигатель (характерный рокот).
* `"electric"` — тихий электромотор с футуристичным свистом.
* `"legacy_pickup"` — ретро-пикап.

## 6. 🛠️ Интерактивная настройка в игре (Tuning GUI)

Для точной балансировки физики без ручного редактирования JSON используйте встроенный тюнер:
1. Заспавните автомобиль: `/car ride <car_id>`
2. Откройте радиальное меню (**Клавиша R**) или введите:
   ```bash
   /car tune <car_id>
   ```
3. В открывшемся графическом интерфейсе можно на лету слайдерами изменять:
   * Клиренс (`ride_height`)
   * Жесткость и отбой подвески
   * Мощность двигателя и максимальную скорость
   * Остроту рулевого управления и баланс тормозов
4. При сохранении настройки автоматически запишутся в `vehicles/<car_id>.json`!

## 7. 🛡️ Чек-лист перед публикацией аддона

- [ ] Файл `vehicles/<id>.json` прошел валидацию через `/car validate <id>`.
- [ ] Все пути к моделям и текстурам используют слэши `/` (не обратные `\`).
- [ ] Точки вращения колес `[0,0,0]` в OBJ строго выровнены по оси ступицы.
- [ ] Водительское место (индекс 0) комфортно ориентировано относительно руля.
- [ ] Окна и двери открываются корректно, хитбоксы дверей не перекрывают друг друга.
- [ ] Проверена стрельба из оружия (TACZ) — пули корректно пробивают стекла и не застревают в невидимых коллизиях кузова.
- [ ] Для пикапов/грузовиков указана категория `"pickup"` или `"is_cargo_bed": true` для задних мест.
